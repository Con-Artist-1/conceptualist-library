# Conceptualist Systems Library - AI Assistant Guide (App Scope)

Welcome! If you are an AI assistant working inside `e:\The Library\search-app`, read this guide before making changes. This React 19 + Vite 8 application powers `https://www.conceptualist.uk` and serves an independent **strictly international exam-board** student study archive (**Pearson Edexcel International** + **Cambridge International CAIE**) indexing **78,820 archived files** (**74,958 deduplicated unique records**) across **169 international subjects**: **19 Edexcel IAL**, **43 Edexcel IGCSE** (`19,944` files / `16,083` unique, Jan 2003 – Jun 2026), plus **31 Cambridge AS & A Level**, **45 Cambridge IGCSE**, and **31 Cambridge O Level** (`58,876` files / `58,875` unique across all 107/107 international syllabuses, 2002 – May/June 2026). UK domestic boards (OCR, UK AQA, UK Edexcel GCE/GCSE, WJEC/Eduqas) are strictly excluded.

## 1. Core Production Scripts (`search-app/scripts/`)

Keep `search-app/scripts/` strictly limited to these **9 core utilities** (do not leave scratch/test scripts behind):

1. **`generate-index.js`**: Scans `Past Papers/` (`IAL`, `IGCSE`, and `Cambridge/{A-Level,IGCSE,O-Level}`), `IAL Books/`, `IGCSE Books/`, and `Cambridge Books/` via board-dispatched `src/unitParser.js` (`src/parsers/edexcelParser.js` & `src/parsers/cambridgeParser.js`), deduplicates variants, and outputs `public/meta.json` (`~0ms` multi-board wizard bootstrap), compact `v: 2` interned `public/index.json` and `public/index-cambridge.json` (`src/lib/indexSerializer.js`), private prefix-grouped `api/_allowlist.json` (used by `api/*.js`), and root `live_index.json` + `live_index_cambridge.json`. Also reports Tier 1 subtitle coverage across `AUD` listening resources from `public/subtitles/manifest.json` (plus legacy `public/audio-subtitles.json` & `.data/audio_subtitles.json` merging). Ignores `toaz.info-*` junk artifacts and merges legacy Physics `WPH07` into `WPH13`.
2. **`build.js`**: Runs the Vite 8 production build (`dist/`) and invokes `prerender-seo.js`.
3. **`prerender-seo.js`**: Reads `meta.json` / `index.json` / `index-cambridge.json` via shared `src/seoRoutes.js` and emits:
   - `public/sitemap.xml` & `dist/sitemap.xml` (indexable canonical URLs across both boards excluding `< 3`-file thin unit routes, covering `/`, `/papers`, `/ial`, `/igcse`, `/cambridge`, `/cambridge/a-level`, `/cambridge/igcse`, `/cambridge/o-level`, `/cambridge/<level>/<slug-code>`, `/textbooks/...`, `/data-files`, `/audio`, `/about`, `/changelog`).
   - `public/llms.txt` & `dist/llms.txt` (structured dual-board AI crawler & LLM index with Pearson/Edexcel and Cambridge non-affiliation notices).
   - Compact JSON route shards in `dist/shards/` (including 4 branch-level IAL Mathematics shards + Cambridge subject shards) for cold-landing speed.
   - Pre-rendered canonical static HTML route pages + `404.html` in `dist/` (`820` routes) with semantic HTML injected directly into `<div id="root">`, `Book` + `ItemList` + `FAQPage` JSON-LD structured data, Open Graph `1200x630` metadata (`public/og-card.png`), legacy spec equivalents, and `683` permanent `308` redirects (including 4-digit Cambridge syllabus codes like `/cambridge/0625`, `/cambridge/9709`, `/cambridge/4024`, and 9–1 equivalents like `/cambridge/0972`) synced into `vercel.json`.
4. **`push-github.js`**: Pushes clean repository files directly to GitHub (`Con-Artist-1/conceptualist-library`) via the GitHub REST API (automatically excludes `node_modules/`, `dist/`, `.data/`, `.env`, etc., while keeping `AI_INSTRUCTIONS_*.md` and `MULTI_BOARD_ARCHITECTURE.md` tracked in GitHub).
5. **`deploy-vercel.js`**: Deploys `search-app` directly to Vercel Production (project/team IDs configured in `.env` / script env) and automatically verifies `https://www.conceptualist.uk/<INDEXNOW_KEY>.txt` before submitting canonical `public/sitemap.xml` URLs to **IndexNow** (`--indexnow-only` / `--skip-indexnow` supported; `"indexnow"` npm script alias in `package.json`). Note that pushing `main` on GitHub also triggers Vercel builds.
6. **`sync-hf.js`**: Syncs library documents (`Past Papers`, `IAL Books`, `IGCSE Books`, `Cambridge Books`) to the Hugging Face dataset (`Diavlon/mcmaster-docs-library`).
7. **`upload-live-index-hf.js`**: Uploads root `live_index.json` and `live_index_cambridge.json` to Hugging Face as resilient client fallbacks.
8. **`sync-sources.js`**: Fast multi-source updater supporting `--board=edexcel` (default: `bsr`, `dp`, `igexams`, `ssc`, `pmt`, `pl`, `elevare`, `beh`, `almr`) and `--board=cambridge` (`beh`, `elevare`, `bsr`, `pmt`, `almr`, `cie`, `papa`, plus `--syllabuses=0625,9709,...`), `--dry-run` (default) / `--apply`, `--sources=`, `--since=YYYY`, `--qpdf=`, `--dump-json=`, `--from-json=`, incremental `.data/library_sha_cache.json` SHA-256 caching, strict international-only isolation (Edexcel IAL vs UK GCE/IGCSE; Cambridge `CAMBRIDGE_SYLLABUSES` whitelist blocking UK domestic GCSE & non-CAIE boards, unifying 9–1 codes onto primary syllabuses, normalizing into `Past Papers/Cambridge/{A-Level,IGCSE,O-Level}/<Subject (Code)>/<Year>/<Series>/`), PDF magic + `%%EOF` trailer + trailing-HTML validation, per-host concurrency semaphores, multi-source fallback retries, `curl.exe` large-file fallback, optional `qpdf` `/ObjStm` optimization, and automatic `generate-index.js` re-indexing.
9. **`index-audio-subtitles.js`**: Incremental offline audio subtitle pre-indexer (`npm run subtitles`). Scans `public/index.json` (or `public/index-cambridge.json` via `--board=edexcel|cambridge|all` + optional `--syllabuses=...`) for `AUD` files (`.mp3`/`.wav`/`.m4a`/`.ogg` and single/nested `.zip` archives), skips tracks already present in `public/subtitles/*.json` by SHA-256 hash, and processes **only newly added tracks** using local Whisper binaries & models in git-ignored `.data/whisper/` (CPU OpenBLAS AVX2 + single Vulkan GPU worker, `--cpu-only`, `--dry-run`, `--force`) with Silero VAD on IGCSE/O-Level, opening & post-reading-pause English rubric probes, and geometry-aware PDF.js verbatim transcript (`Transcript` / `_tn_`) forced alignment, merging results cleanly into `public/subtitles/<shard>.json` and `public/subtitles/manifest.json`.
